# 상담 신청 → 구글 시트 + 슬랙 연결 방법

웹사이트 폼 → **Google Apps Script(웹 앱)** → ① 구글 시트에 한 줄 저장 ② 슬랙 채널에 알림

별도 서버 없이 무료로 동작하고, 슬랙 주소(웹훅)는 구글 쪽에만 저장되어 웹사이트에 노출되지 않습니다.

---

## 1. 슬랙 웹훅 만들기 (알림 받을 채널 정하기)

1. https://api.slack.com/apps → **Create New App** → From scratch
2. 앱 이름(예: `렌탈 신청 알림`), 워크스페이스 선택
3. 왼쪽 **Incoming Webhooks** → 켜기(On) → **Add New Webhook to Workspace**
4. 알림 받을 채널 선택 → 허용
5. 생성된 `https://hooks.slack.com/services/...` 주소를 복사해 둡니다

## 2. 구글 시트 + Apps Script 준비

1. 새 구글 시트를 만듭니다 (예: `페이앤밴 렌탈 신청`)
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 `Code.gs` 내용을 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](../apps-script/Code.gs) 내용을 붙여넣고 저장
4. 왼쪽 톱니바퀴 **프로젝트 설정 → 스크립트 속성 → 속성 추가**
   - 속성: `SLACK_WEBHOOK_URL`
   - 값: 1번에서 복사한 웹훅 주소
5. 편집기 상단 함수 목록에서 `setup` 선택 → **실행** → 권한 승인
   - "확인되지 않은 앱" 경고가 나오면 고급 → 이동 을 눌러 승인합니다 (본인이 만든 스크립트입니다)
   - 시트에 `신청목록` 탭과 머리글이 생깁니다
6. (선택) `testSubmit` 실행 → 시트에 테스트 한 줄 + 슬랙 알림이 오면 성공

## 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(톱니바퀴) → **웹 앱**
3. 설정
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`) 복사

## 4. 웹사이트에 주소 넣기

[`public/js/config.js`](../public/js/config.js) 의 `FORM_ENDPOINT` 에 붙여넣습니다.

```js
FORM_ENDPOINT: "https://script.google.com/macros/s/xxxxxxxx/exec",
```

커밋 후 넷리파이에 다시 올리면 끝입니다. 비워두면 폼은 **테스트 모드**로 동작해서(화면 흐름만 확인) 실제 전송이 되지 않습니다.

---

## 시트에 쌓이는 정보

| 접수일시 | 처리상태 | 매장 상태 | 업종 | 휴대폰 | 연락 희망일 | 연락 희망 시간 | utm_source … | 유입 경로 | 랜딩 URL | 기기 정보 |
| -------- | -------- | --------- | ---- | ------ | ----------- | -------------- | ------------ | --------- | -------- | --------- |

- **처리상태** 열은 `신규`로 들어옵니다. 상담 후 `연락완료`, `계약` 등으로 직접 바꿔 관리하세요.
- 광고 링크에 `?utm_source=daangn&utm_campaign=1030` 처럼 붙이면 어느 광고에서 들어왔는지 함께 저장됩니다.
- 같은 번호로 10분 안에 다시 신청하면 중복으로 보고 저장하지 않습니다.

## 코드를 고친 뒤에는

Apps Script 코드를 수정했다면 **배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포** 를 해야 반영됩니다.
이렇게 하면 웹 앱 URL은 그대로 유지됩니다. ("새 배포"를 다시 만들면 URL이 바뀌니 주의)
