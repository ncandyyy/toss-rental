# 상담 신청 → 구글 시트 + 슬랙 연결 방법

웹사이트 폼 → **Google Apps Script(웹 앱)** → ① 구글 시트에 한 줄 저장 ② 슬랙 채널에 알림

별도 서버 없이 무료로 동작하고, 슬랙 주소(웹훅)는 구글 쪽에만 저장되어 웹사이트에 노출되지 않습니다.

---

## 1. 슬랙 웹훅 만들기 (알림 받을 채널 정하기)

두 가지 중 편한 방법을 쓰면 됩니다. Apps Script 가 주소 모양을 보고 알아서 맞춰 보냅니다.

### A. 워크플로 빌더 웹훅 (`hooks.slack.com/triggers/...`) — 메시지 모양을 슬랙에서 직접 꾸밀 때
1. 슬랙 → 워크플로 빌더 → 새 워크플로 → 시작 방법 **웹훅에서 시작**
2. 변수를 아래 이름 그대로 만듭니다 (모두 텍스트)

   | 변수 | 내용 | 예 |
   | --- | --- | --- |
   | `storeStatus` | 매장 상태 | 매장 운영 중 |
   | `industry` | 업종 | 카페 · 디저트 |
   | `phone` | 휴대폰 | 010-1234-5678 |
   | `contactDay` | 연락 희망일 (요일) | 월요일 |
   | `contactDate` | 연락 희망일 (날짜) | 2026-11-09 |
   | `contactTime` | 연락 희망 시간 | 오후 14시 |
   | `receivedAt` (선택) | 접수일시 | 2026-11-06 10:31:05 |
   | `sheetUrl` (선택) | 시트 해당 행 바로가기 | https://docs.google.com/... |

   선택 변수를 만들었다면 `apps-script/Code.gs` 의 `SLACK_FIELDS` 에도 이름을 추가하세요.
3. 다음 단계 **채널에 메시지 보내기** 에서 변수를 넣어 메시지를 꾸미고 게시
4. 생성된 `https://hooks.slack.com/triggers/...` 주소를 복사

### B. 수신 웹훅 (`hooks.slack.com/services/...`) — 정해진 모양으로 바로 받을 때
1. https://api.slack.com/apps → **Create New App** → From scratch
2. 앱 이름(예: `렌탈 신청 알림`), 워크스페이스 선택
3. 왼쪽 **Incoming Webhooks** → 켜기(On) → **Add New Webhook to Workspace**
4. 알림 받을 채널 선택 → 허용
5. 생성된 `https://hooks.slack.com/services/...` 주소를 복사

어느 쪽이든 웹훅 주소는 비밀번호처럼 다루세요. 코드나 저장소에 넣지 말고 아래 2단계의 스크립트 속성에만 넣습니다.

## 2. 구글 시트 + Apps Script 준비

1. 새 구글 시트를 만듭니다 (예: `페이앤밴 렌탈 신청`)
2. 메뉴 **확장 프로그램 → Apps Script**
3. 기본 `Code.gs` 내용을 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](../apps-script/Code.gs) 내용을 붙여넣고 저장
4. 왼쪽 톱니바퀴 **프로젝트 설정 → 스크립트 속성 → 속성 추가**
   - 속성: `SLACK_WEBHOOK_URL`
   - 값: 1번에서 복사한 웹훅 주소
5. 편집기 상단 함수 목록에서 `setup` 선택 → **실행** → 권한 승인
   - "확인되지 않은 앱" 경고가 나오면 고급 → 이동 을 눌러 승인합니다 (본인이 만든 스크립트입니다)
   - 시트에 `신청목록` 탭과 머리글이 생깁니다
6. (선택) `testSubmit` 실행 → 시트에 테스트 한 줄 + 슬랙 알림이 오면 성공 (확인 후 테스트 행은 지우세요)
7. 설정과 테스트가 끝나면 `Code.gs` 맨 아래 **일회용** 구역(`setup`, `testSubmit`)은 지워도 됩니다.

## 3. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 유형 선택(톱니바퀴) → **웹 앱**
3. 설정
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`) 복사

## 4. 웹사이트에 주소 넣기

[`public/js/config.js`](../public/js/config.js) 의 `FORM_ENDPOINT` 에 붙여넣습니다.

```js
FORM_ENDPOINT: "https://script.google.com/macros/s/xxxxxxxx/exec",
```

커밋 후 넷리파이에 다시 올리면 끝입니다. 비워두면 폼은 **테스트 모드**로 동작해서(화면 흐름만 확인) 실제 전송이 되지 않습니다.

## 시트에 쌓이는 정보

| 열 | 내용 | 슬랙 알림 |
| --- | --- | --- |
| A 접수일시 | 신청이 들어온 시간 (한국 시간) | ✅ |
| B 매장 상태 | 신규 매장 준비중 / 매장 운영 중 | ✅ |
| C 업종 | 업종 선택값 | ✅ |
| D 휴대폰 | 010-1234-5678 | ✅ |
| E 연락 희망일 | 예: `월요일 (2026-11-09)` | ✅ (희망 시간과 함께) |
| F 연락 희망 시간 | 예: `오후 14시`, `언제든 가능` | ✅ |
| G 처리상태 | `신규`로 들어옴 → 상담 후 직접 변경 | 시트에만 |
| H 개인정보 동의 | `동의` (동의 시점 = 접수일시) | 시트에만 |
| I~M utm_source ~ utm_term | 광고 링크에 붙인 값 | 시트에만 |
| N 유입 경로(referrer) | 이전 페이지 주소 | 시트에만 |
| O 랜딩 URL | 처음 들어온 주소 | 시트에만 |
| P 기기 정보 | 브라우저·기기 정보 | 시트에만 |

- **G~P 열은 기록용**이라 한꺼번에 숨기기 좋게 뒤쪽에 모아두었습니다. (G열 머리글부터 P열까지 선택 → 우클릭 → 열 숨기기)
- 광고 링크에 `?utm_source=daangn&utm_campaign=1030` 처럼 붙이면 어느 광고에서 들어왔는지 함께 저장됩니다.
- 같은 번호로 10분 안에 다시 신청하면 중복으로 보고 저장하지 않습니다.
- 이미 예전 코드로 `setup` 을 실행해 머리글이 만들어져 있다면, `신청목록` 탭을 지우고 새 코드로 `setup` 을 다시 실행하세요.

## 연락 희망일 (주말·공휴일 제외)

신청 화면의 연락 희망일 버튼 2개는 **주말과 쉬는 날을 건너뛴 가까운 영업일**로 바뀝니다.

| 신청하는 때 | 버튼 |
| --- | --- |
| 월~목 상담 시간 중 | 오늘 / 내일 |
| 목요일 저녁 (오늘 상담 끝남) | 금요일 / 월요일 |
| 금요일 상담 시간 중 | 금요일 / 월요일 |
| 금요일 저녁 · 토 · 일 | 월요일 / 화요일 |

- 오늘을 고르면 이미 지난 시간은 선택할 수 없습니다.
- 공휴일·회사 휴무일은 `public/js/config.js` 의 `HOLIDAYS` 에 `"YYYY-MM-DD"` 로 추가하면 건너뜁니다.

## 상단 바 누적 조회수

같은 웹 앱 주소가 페이지 방문 수도 셉니다. 따로 설정할 것은 없습니다.

- 방문자가 처음 들어올 때 1 올라가고, 같은 탭에서 새로고침하면 다시 세지 않습니다.
- 숫자는 Apps Script **프로젝트 설정 → 스크립트 속성 → `VIEW_COUNT`** 에 저장됩니다.
- 무료 구글 계정 기준 Apps Script 속성 읽기/쓰기 한도는 하루 약 5만 회라, 하루 2만 명 정도까지는 문제없습니다.
- `FORM_ENDPOINT` 가 비어 있으면(테스트 모드) HTML 에 적힌 기본 숫자(24)가 보입니다.

## 코드를 고친 뒤에는

Apps Script 코드를 수정했다면 **배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포** 를 해야 반영됩니다.
이렇게 하면 웹 앱 URL은 그대로 유지됩니다. ("새 배포"를 다시 만들면 URL이 바뀌니 주의)
