# 영상 파일 넣는 곳

피그마의 영상 레이어는 MCP로 내려받을 수 없어서, 지금은 영상의 첫 장면 이미지(포스터)가 대신 보입니다.
아래 이름으로 mp4 파일을 이 폴더에 넣으면 자동으로 재생됩니다. (소리 없이, 반복 재생)

| 파일 이름 | 위치 | 피그마 레이어 |
| --- | --- | --- |
| `place-pos-pay-process-2.mp4` | 기능 캐러셀 2번 슬라이드 "고객 관리는 자연스럽게" | `place-pos-pay-process-2 (1) 1` |

권장: H.264 mp4, 가로 1348px 안팎, 5MB 이하 (용량이 크면 모바일에서 늦게 뜹니다)

다른 이미지를 영상으로 바꾸고 싶으면 `index.html` 에서 2번 슬라이드의 `<video data-src="...">` 부분을 참고해 같은 구조로 넣으면 됩니다.
